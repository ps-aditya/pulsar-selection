Headline: the forest ranks well (ROC-AUC 0.978), but no calibrator helped, and the cost model set the cut-off at 0.54, not the textbook 0.09 (gap not yet explained).

The problem

  • A radio survey flags thousands of "maybe-pulsar" signals. Almost all are interference or noise.
  • Pulsar: a spinning dead star that blinks like a lighthouse.
  • Only 9.16% of candidates are real (1,639 of 17,898).

Why not accuracy?

A model that always says "not a pulsar" scores 90.8% accuracy and finds 0 pulsars.

So we report ROC-AUC, PR-AUC, precision, recall, and Brier score.

What the brief asked for

  • ROC-AUC ≥ 0.97  MET
  • Recall ≥ 0.90 at precision ≥ 0.90  NOT MET
  • Brier improves after calibration  NOT MET
  • Split before any resampling  DONE
  • Threshold from a cost model  DONE
  • Learning curve + importance  DONE

Cut-off from a cost model

Missed pulsar (FN) = 10. Wasted follow-up (FP) = 1. Pick the threshold that minimises total cost on train+val.

Minimum at T = 0.54: 0 missed pulsars, 42 false alarms (selection set). Ratios 5:1, 10:1 and 20:1 all pick it.

How many labels are needed?

CV PR-AUC rises to ~0.92 by ~5,500 labels, then flattens. Only tested up to 7,159 labels (2/3 of train).

What did it learn?

Profile kurtosis (how sharply the pulse peaks) matters 17× more than any other feature. Real pulsars fold to a sharp, repeating blink; interference folds flat. Dispersion statistics refine the decision but do not carry it.

What we did

  • Leakage-audited, stratified split before any weighting
  • Logistic regression baseline and CV-tuned Random Forest
  • Four-way calibration study, chosen by cross-validated Brier
  • Written 10:1 cost model; threshold 0.54, 5:1–20:1 agree
  • One final test evaluation with bootstrap CIs and ECE
  • Permutation importance, read against the physics

What we did not achieve

  • Recall ≥ 0.90 at precision ≥ 0.90: not met (recall 0.857)
  • Brier better after calibration: not met; no calibrator won
  • Threshold gap: textbook 0.09 vs measured 0.54, unexplained
  • Misses are confidently wrong: 47 of 328 pulsars, median score ~0.1; threshold moves do not recover them
  • Scope: 10:1 cost is a stated choice; one survey, eight summary numbers; no new pulsars found
